# Stitches by S — Embroidery Design Showcase

A lightweight animated HTML showcase for client presentation.

## Designs
- SBEMB-780
- SBEMB-779
- SBEMB-778
- SBEMB-777

## Features
- Responsive 2-column gallery
- Smooth entrance animation
- Subtle thread-like light sweep
- Hover zoom effect
- Full-screen image viewer
- No external libraries or dependencies

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and all four PNG files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save and open the generated Pages URL.

The four images are kept in the same folder as `index.html`, so the gallery works directly on GitHub Pages.
